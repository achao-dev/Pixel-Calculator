# Pixel Calculator
A cute, pixel-art scientific calculator inspired by retro games.

## Overview
**Pixel Calculator** is a personal project I'm building for fun to help improve my frontend development and coding skills, and gain experience developing an application independently.

*The goal is to combine a nostalgic pixel-art aesthetic with practical scientific calculator functionality.*

## Planned Features
- [ ] **Basic arithmetic:** *Addition, subtraction, multiplication and division*
- [ ] **Scientific functions:** *Square roots, powers and trigonometric functions*
- [ ] **Calculator controls:** *Clear and delete*
- [ ] **Customisation:** *Five colour themes*
- [ ] **Keyboard support**

## Colour Themes
